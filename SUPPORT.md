# Support

## Bug reports and feature requests

Please use GitHub Issues:

- Bug report: include steps to reproduce, expected behavior, observed behavior, and environment details.
- Feature request: include the use case, expected benefit, and possible alternatives.

## Usage questions

Open a GitHub issue with the label `question` and include:

- Operating system and Python version
- Install method and dependency versions
- Relevant logs or traceback (remove sensitive data)

## Security and privacy issues

Do not post sensitive patient or institutional data in public issues.
For vulnerabilities, open a private security advisory in GitHub if available, or contact the maintainer directly before public disclosure.

## Support expectations

This project is currently maintained on a best-effort basis by a single maintainer.
Response times can vary depending on research and clinical workload.
